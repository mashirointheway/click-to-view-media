Quiet by default.

Click to View Media treats every page like someone is reading over your shoulder. Nothing is deleted or blocked. Pictures and videos simply wait for your click.

Pictures of every kind

Ordinary images, videos, drawings and icons, chat emotes, image buttons, and pictures that pages use as backgrounds all get the same treatment.

Blur that fits the moment

Open the extension's toolbar popup and drag the slider to choose how strong the blur is, from light to heavy. The setting follows you from page to page. Click a blurred item to see it, then click it again to hide it. If one site needs a break, turn it off there in the same popup.

YouTube stays quiet

When a video ad starts, the sound is muted, and your volume comes back when the ad ends. If a Skip button appears, it is clicked for you.

Keeps up with busy pages

Pages that load more as you scroll, move between sections without reloading, or show content from other places can't leave pictures behind. New pictures are blurred before they show up, so nothing flashes on screen.

One item at a time

Each picture and video is controlled separately. Uncover one and the rest of the page stays as hidden as it was before.

Private by design

No account, no server, no tracking. The only things saved are your blur strength and any sites you have turned off. They stay on your device.

Install on Chrome.

Extensions that don't come from the Chrome Web Store have to be installed by hand, in Developer mode. Download the ZIP, unzip it, and point Chrome at the folder.

Everything happens inside your browser. No account, no server, no tracking.

Download the ZIP
  1. Download and unzip Keep the folder somewhere permanent, because Chrome loads the extension from that location each time it starts.
  2. Open Chrome's extension page Go to chrome://extensions and turn on Developer mode.
  3. Load the folder Choose Load unpacked and select the folder you unzipped. It is the one that contains a file named manifest.json.
  4. Set your blur Pin the extension, click its toolbar icon, and choose how strong the blur should be. Reload any open tabs so the change applies there.

Firefox on Android.

This version is built on your computer and copied to Firefox Beta on your phone over a USB cable. There is no app store listing and no account to create. Firefox treats it as a temporary test copy, so it disappears when the browser closes.

  • Firefox Beta 142 or newer
  • Node.js 18 or newer
  • USB debugging on

You'll need Firefox Beta on the phone, Node.js on your computer, and USB debugging turned on. The extension is loaded from the dist/firefox folder.

Read the Android guide

Temporary by design. Firefox removes the extension when it closes. Run the command again to load it back onto the phone.

  1. Get the source Download the project. You only need Node.js 18 or newer. The first command downloads the extra tool it needs.
  2. Build the Firefox folder Run npm run build:firefox. It creates the dist/firefox folder that Firefox will load.
  3. Connect Firefox Beta Turn on USB debugging on the phone, plug it in, and check that adb devices lists it. Firefox Beta 142 or newer is required.
  4. Run it Run npm run run:android and leave the terminal window open. Firefox Beta opens on the phone with the extension loaded.
  5. Open the popup In Firefox on the phone, open the menu, go to Extensions, and tap Click to View Media to change the blur.
